# Плейбук донастройки

Оптимизация идёт снизу вверх по плоскости **кампания → группа → условие показа**. Разбирать поиск и РСЯ **раздельно**, средние по ним не смешивать.

## Порядок разбора

1. **Поисковые запросы и площадки.** Сортировка по показам, особое внимание — большие показы без кликов. Площадку РСЯ отключать, если её стоимость конверсии **вдвое выше средней**.
2. **Таргетинги (условия показа).** Отключать те, где CPA **≥ 2× средней**.
3. **Группы объявлений.** CPA ≥ 2× средней — отключать; CPA в диапазоне **1,5×–2×** средней — снижать ставки, а не рубить.
4. **Кампании.** Отключать при CPA **≥ 3× средней** или если корректировки не помогли.
5. **Если нужно снизить показы** — уменьшать бюджет, снижать ставки, применять временные корректировки.
6. **Микроконверсии.** При малом объёме основной конверсии оптимизироваться на промежуточные действия (клик по номеру, корзина, время на сайте). Сначала — по основной конверсии, микро — как временный костыль для обучения.
7. **CTR.** Смотреть только группы с **10+ кликами**, иначе шум. Низкий CTR — сигнал рассогласования таргетинга и текста объявления.

## Частота

- **Ежедневно** — выявление отклонений (расход, отсутствие показов, обрыв конверсий).
- **Еженедельно** — полная оптимизация по списку выше.
- **Ежеквартально** — масштабный анализ на 3+ месяцах данных.

## Чего не делать

- Не трогать конверсионную стратегию во время обучения: смена цели, атрибуции, ограничения расхода — переобучение (см. «Стратегии и бюджеты» (`direct://kb/strategies-budgets`)).
- Не оценивать результат раньше 7–14 дней.
- Не резать таргетинги «на всякий случай»: сужение режет охват, а автостратегиям нужен объём данных.
- Не добавлять минус-фразу, полностью пересекающуюся с ключевой — она будет проигнорирована (см. «Ключевые фразы, минус-слова, операторы» (`direct://kb/keywords-negatives`)).
- Не оставлять включённым автоприменение рекомендаций Директа — оно переписывает настройки мимо вас.
- Не делать паузы дольше 7 дней, и тем более 28 дней — обучение стратегии сбросится.

## Диагностика «нет показов / мало открутки»

Проверять по порядку: статус модерации → баланс и остановки → статус «Мало показов» у групп → ставки и потолок `BidCeiling` → корректировки с большим минусом → узость гео и минус-слов → низкочастотность семантики (недельный бюджет физически не выбирается).

Агентская оценка: типовая кампания теряет **20–40% бюджета** на систематических ошибках, накапливающихся со временем — поэтому регулярный аудит по чек-листу важнее разовой идеальной настройки.
