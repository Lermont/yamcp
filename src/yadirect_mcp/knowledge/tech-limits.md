# Технические ограничения Директа

Официальные лимиты для ТГО в ЕПК. **Проверять их до вызова API**: превышение стоит 20 баллов за ошибку и раунд правок.

## Символы в объявлении

| Элемент | Лимит |
|---|---|
| Заголовок | 56 знаков (включая пробелы и знаки препинания), одно слово ≤ 22 символов |
| Дополнительный заголовок | 30 символов + 15 знаков препинания, слово ≤ 22 знаков |
| Текст объявления | 81 символ + 15 знаков препинания, слово ≤ 23 знаков |
| Ссылка | 1024 знака включая протокол |
| Отображаемая ссылка | 20 знаков (домен не считается) |
| Быстрая ссылка | заголовок 30 знаков, описание ≤ 60 знаков |
| Уточнение | 25 знаков; суммарно на объявление ≤ 132 символов на десктопе и ≤ 76 на мобильных |
| Текст для продвижения приложений | 75 знаков, слово ≤ 23 знаков |

## Фразы, группы, аккаунт

| Объект | Лимит |
|---|---|
| Ключевая фраза | 4096 символов, **не более 7 слов** во фразе |
| Ключевых фраз на группу | не более 200 |
| Минус-фразы на группу | 4096 символов без учёта пробелов, ≤ 7 слов во фразе |
| Минус-фразы на кампанию | 20 000 символов без учёта пробелов |
| Объявлений в группе | до 50 |
| Групп в кампании | до 1000 |
| Кампаний в аккаунте | до 3000, из них не более 1000 активных |
| Видео | 5–60 с (для товаров 5–45 с), не более 100 Мб |

## Практические следствия

- Заголовок 56 знаков — это лимит, а не цель: длинные заголовки обрезаются в части блоков. Ключевую фразу лучше вносить в начало заголовка.
- Лимит «7 слов во фразе» ломает длинные хвосты семантики: такие фразы надо укорачивать, а не отбрасывать.
- 20 000 символов минус-фраз на кампанию расходуются быстрее, чем кажется, при машинной генерации минусовки из отчёта по поисковым запросам — следить за объёмом.
- Модерация проходит обычно за несколько часов. Отклоняют за абстрактный объект продвижения, некачественные изображения, запрещённые категории (казино, азартные игры, алкоголь). Лицензируемые тематики (медицина, детское питание, здоровье и красота) требуют документов.
