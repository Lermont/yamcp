# Технические ограничения Директа

Официальные лимиты для ТГО в ЕПК. **Проверять их до вызова API**: превышение стоит 20 баллов за ошибку и раунд правок.

Для числа комбинаторных объявлений действует отдельный лимит:
[3 неархивных и 10 вместе с архивными](https://yandex.ru/support/direct/ru/unified-performance-campaign/create-comb-ad).
Он проверяется при создании; перенесённые Яндексом старые группы с большим
числом проверяются с учётом миграции. Архивные объявления нельзя считать
прочитанными, если аудит запрашивал только неархивные.

## Символы в объявлении

«Узкие» символы перечислены в [Ads.get](https://yandex.ru/dev/direct/doc/ru/ads/get):
`!,.;:"`. Формулировка API — не более 81 остальных символов и не более 15 узких;
самовольного расширения после 15-го символа валидатор не делает. Число `Texts`
в API — 1–3, а ровно 3 текста — действующее требование агентской политики.
Общие проверки символов, слов и отображаемого пути находятся в `limits.py`.

| Элемент | Лимит |
|---|---|
| Заголовок | 56 знаков (включая пробелы и знаки препинания), одно слово ≤ 22 символов |
| Дополнительный заголовок | 30 символов + 15 знаков препинания, слово ≤ 22 знаков |
| Текст объявления | 81 символ + 15 знаков препинания, слово ≤ 23 знаков |
| Ссылка | 1024 знака включая протокол |
| Отображаемая ссылка | 20 знаков (домен не считается) |
| Быстрая ссылка | заголовок 30 знаков, описание ≤ 60 знаков |
| Быстрых ссылок в наборе | агентский минимум 4, рекомендуется 8; технический лимит API 1–8 |
| Уточнение | 25 знаков; суммарно на объявление ≤ 132 символов на десктопе и ≤ 76 на мобильных |
| Текст для продвижения приложений | 75 знаков, слово ≤ 23 знаков |

## Фразы, группы, аккаунт

| Объект | Лимит |
|---|---|
| Ключевая фраза | 4096 символов, **не более 7 слов** во фразе |
| Ключевых фраз на группу | не более 200 |
| Минус-фразы на группу | 4096 символов без учёта пробелов, ≤ 7 слов во фразе |
| Минус-фразы на кампанию | 20 000 символов без учёта пробелов |
| Комбинаторных объявлений в новой группе ЕПК | не более 3 неархивных, 10 вместе с архивными; MCP начинает с 1 |
| Групп в кампании | до 1000 |
| Кампаний в аккаунте | до 3000, из них не более 1000 активных |
| Видео | 5–60 с (для товаров 5–45 с), не более 100 Мб |

## Практические следствия

- В политике 1.6.0 компилятор и executor проверяют 1000 групп, 200 обычных ключей
  на группу, явные дубли и лимиты строки до записи. Служебный автотаргетинг считается
  отдельно. Лимит API: 7 слов без минус-слов и стоп-слов; локальный разбор учитывает
  распространённые служебные слова и наиболее длинную ветвь альтернатив, но не
  воспроизводит всю обработку языка Яндексом. Ориентиры количества ниже технических
  пределов описаны в `direct://kb/structure-semantics`.
- Внутренний стандарт MCP: минимум 3 заголовка в каждом комбинаторном объявлении занимают 45–56 знаков. Остальные варианты могут быть короче ради разнообразия; ключевую фразу и объект продвижения лучше ставить в начало, а формулировку не растягивать пустыми словами.
- Лимит «7 слов во фразе» ломает длинные хвосты семантики: такие фразы надо укорачивать, а не отбрасывать.
- 20 000 символов минус-фраз на кампанию расходуются быстрее, чем кажется, при машинной генерации минусовки из отчёта по поисковым запросам — следить за объёмом.
- Модерация проходит обычно за несколько часов. Отклоняют за абстрактный объект продвижения, некачественные изображения, запрещённые категории (казино, азартные игры, алкоголь). Лицензируемые тематики (медицина, детское питание, здоровье и красота) требуют документов.

См. также: «Контракт записи в Direct API» (`direct://kb/api-contract`), «Ключевые фразы, минус-слова, операторы» (`direct://kb/keywords-negatives`), «Чек-лист первичной настройки» (`direct://kb/launch-checklist`)
