# Метрика, цели и ценность конверсии

**Без счётчика Метрики с настроенными целями конверсионные стратегии не работают.** Это первое, что нужно выяснить до любой настройки: есть ли счётчик, есть ли доступ на редактирование, какие цели настроены, фиксируются ли они на самом деле.

## Целевые действия

- В одну кампанию можно добавить **до 30 целевых действий**.
- Поддерживаются составные цели Метрики и ecommerce-цели. Автоцели Метрика создаёт сама и по умолчанию это включено.
- Если продвигаются и сайт, и профиль организации — добавлять минимум по одной цели на каждый канал.
- **Вовлечённые сессии** — то, на что «Максимум кликов» ориентируется по умолчанию (рассчитанные системой целевые действия и средняя ценность конверсии на сайте). Практика eLama: заменять их на реальное бизнес-действие — заявку, звонок, покупку.
- Алгоритму проще обучаться на **одной** цели, чем на нескольких. Много целей — распыление данных.

## Ценность конверсии

- Минимальная ценность конверсии — **30 копеек**. Количество ключевых целей в кампании не ограничено.
- **Независимые цели:** номинальная ценность каждой (заказ звонка 50 ₽, просмотр товара 10 ₽, оформленный заказ 180 ₽).
- **Зависимые цели** (каждая следующая требует предыдущей): ценность считается через конверсионные коэффициенты этапов воронки.
- Формула eLama: `средняя прибыль со сделки × конверсия этапа`. Прибыль 10 000 ₽ и 5% конверсии из заявки в сделку → ценность цели «заявка» = 500 ₽.
- **Ценности целей внутри кампании должны заметно различаться** — 600 против 1000, а не 600 против 700, иначе система не понимает приоритет.
- Для ecommerce в «Максимум конверсий» можно использовать динамическую ценность (разный доход по товарам).

## Атрибуция

- В API ЕПК: `AUTO` по умолчанию, также `FCCD`, `LC`, `LSCCD`. В отчётах Reports API набор шире: `FC`, `LC`, `LSC`, `LYDC`, `FCCD`, `LSCCD`, `LYDCCD`, `AUTO`; по умолчанию `LSC`.
- Короткий цикл сделки — «последний значимый переход»; длинный — «первый переход».
- **Модель атрибуции менять во время обучения стратегии нельзя** — уходит в переобучение.

## Типичные проблемы

1. Цели не фиксируются — проверять установку счётчика и настройку целей до разбора ставок.
2. Перерасход — задать недельный бюджет и реалистичные ценности.
3. Мало показов из-за целей — уменьшить количество целей или взять более достижимые.
