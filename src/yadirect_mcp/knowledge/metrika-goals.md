# Метрика, цели и ценность конверсии

## Специальный GoalId=13 — поддержка в плане с 18.09.2026

В maximum_conversion_rate можно указать strategy.goal_id=13 — использовать
ключевые цели кампании. В priority_goals нужен минимум один реальный ID кроме
системной цели 12. Сам 13 в priority_goals запрещён. Preflight проверяет реальные
бизнес-цели по каталогу, без запроса системных 12/13 как обычных целей. Счётчик
и осознанный выбор целей по-прежнему требуются. Readback сверяет GoalId стратегии.

Отчёты раскрывают 13 в PriorityGoals; пустой набор, одинокая 12 или наличие 13
в наборе дают недостоверный источник целей, а не положительную проверку.
Системные события нельзя называть подтверждёнными лидами.

Для `maximum_clicks` счётчик и бизнес-цели необязательны: `counter_ids` и
`priority_goals` можно опустить или передать пустыми массивами. Компилятор
не отправляет пустые `CounterIds`/`PriorityGoals` и не подставляет фиктивную
цель. Если цели не выбраны, `goals_reviewed`, каталог целей и
`allow_unverified_goals` не требуются. Счётчик без выбранных целей допустим.
Если бизнес-цели указаны, сохраняются проверка счётчика, ручное подтверждение
целей и live-проверка каталога. Для `maximum_conversion_rate` по-прежнему
обязательны счётчик и явный `goal_id` из `priority_goals` либо селектор 13
при наличии хотя бы одной приоритетной цели кроме системной 12.

Основание: [UnifiedCampaign.add](https://yandex.ru/dev/direct/doc/ru/campaigns/add-unified-campaign):
`CounterIds` необязателен, `WB_MAXIMUM_CLICKS` не требует `GoalId` или
`PriorityGoals`. Проверено 09.09.2026.

**Без счётчика Метрики с настроенными целями конверсионные стратегии не работают.** Это первое, что нужно выяснить до любой настройки: есть ли счётчик, есть ли доступ на редактирование, какие цели настроены, фиксируются ли они на самом деле.

## Целевые действия

- В одну кампанию можно добавить **до 30 целевых действий**.
- Поддерживаются составные цели Метрики и ecommerce-цели. Автоцели Метрика создаёт сама и по умолчанию это включено.
- Если продвигаются и сайт, и профиль организации — добавлять минимум по одной цели на каждый канал.
- **Вовлечённые сессии** — то, на что «Максимум кликов» ориентируется по умолчанию (рассчитанные системой целевые действия и средняя ценность конверсии на сайте). Практика eLama: заменять их на реальное бизнес-действие — заявку, звонок, покупку.
- Алгоритму проще обучаться на **одной** цели, чем на нескольких. Много целей — распыление данных.

## Ценность конверсии

- Минимальная ценность конверсии — **30 копеек**. Количество ключевых целей в кампании не ограничено.
- **Независимые цели:** номинальная ценность каждой (заказ звонка 50 ₽, просмотр товара 10 ₽, оформленный заказ 180 ₽).
- **Зависимые цели** (каждая следующая требует предыдущей): ценность считается через конверсионные коэффициенты этапов воронки.
- Формула eLama: `средняя прибыль со сделки × конверсия этапа`. Прибыль 10 000 ₽ и 5% конверсии из заявки в сделку → ценность цели «заявка» = 500 ₽.
- **Ценности целей внутри кампании должны заметно различаться** — 600 против 1000, а не 600 против 700, иначе система не понимает приоритет.
- Для ecommerce в «Максимум конверсий» можно использовать динамическую ценность (разный доход по товарам).

## Атрибуция

- В API ЕПК доступны `AUTO`, `FCCD`, `LC`, `LSCCD`. В Reports API актуален тот
  же набор; сам API по умолчанию использует `LC`, но MCP для конверсионного
  отчёта явно передаёт модель, прочитанную из кампании, либо заданную для сравнения.
  Цель стратегии 13 раскрывается в реальные приоритетные цели. Разные настройки
  кампаний требуют отдельных отчётов или явных параметров, см. `direct://kb/report-recipes`.
  Устаревшие `LSC`, `FC`, `LYDC`,
  `LYDCCD` Direct может преобразовать с предупреждением, поэтому MCP их не
  отправляет.
- Короткий цикл сделки — «последний значимый переход»; длинный — «первый переход».
- **Модель атрибуции менять во время обучения стратегии нельзя** — уходит в переобучение.

## Типичные проблемы

1. Цели не фиксируются — проверять установку счётчика и настройку целей до разбора ставок.
2. Перерасход — задать недельный бюджет и реалистичные ценности.
3. Мало показов из-за целей — уменьшить количество целей или взять более достижимые.
