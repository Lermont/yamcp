# Changelog

Все заметные изменения проекта документируются в этом файле. Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии следуют [Semantic Versioning](https://semver.org/lang/ru/).

## [Unreleased]

### Fixed

- Запуск `python -m yadirect_mcp` — команда из всех примеров подключения падала с `cannot be directly executed`, потому что в пакете не было `__main__.py`.
- Отчёт больше не теряется, если в TSV попалась строка с лишним разделителем: файл сохраняется до разбора, а ошибка возвращается полем `parse_error`.
- Итоги по отчётам с целями Метрики: колонки вида `Conversions_<цель>_<атрибуция>` больше не выпадают из `totals`, производные метрики пересчитываются по каждой цели.
- Поллинг офлайн-отчёта переживает нечисловой заголовок `retryIn` вместо аварийного завершения.
- Ответы `502`, `503` и `504` от балансировщика повторяются, а не отбрасывают уже поставленный в очередь отчёт.
- Частичное создание объектов кампании: ID из успешных пакетов сохраняются в ответе, если следующий пакет упал.
- Выгруженный TSV записывается байт в байт как пришёл от API, без подстановки CRLF на Windows.

### Security

- Каталог `YD_OUT_DIR` закрыт и на запись: `client_login` с `..` и разделителями пути больше не уводит файл отчёта за его пределы.

### Planned

- Яндекс Метрика, пакетные отчёты и дисковый кеш закрытых периодов.

## [0.2.0] - 2026-07-16

### Added

- Защищённый режим `campaign_setup`.
- Preview и точная confirmation-фраза перед записью.
- Последовательное создание кампании, групп, объявлений и ключевых фраз.
- Сохранение созданных ID и ошибок при частично выполненной операции.
- Полная документация для Windows, Linux, Claude Code, Codex, Hermes и ZCode.
- GitHub Actions CI, шаблоны сообщества и релизная документация.

### Security

- Режим отчётности остаётся режимом по умолчанию.
- Кампания не активируется автоматически.
- Родительские ID запрещено передавать во вложенных объектах.

## [0.1.0] - 2026-07-16

### Added

- MCP-инструменты `direct_list_clients`, `direct_campaigns`, `direct_report` и `direct_read_report`.
- Поддержка онлайн- и офлайн-отчётов Яндекс Директа.
- Сохранение TSV, totals, preview и постраничное чтение.
- Белый список клиентских логинов и контроль очереди отчётов.
