## [Unreleased]

### Added

- `direct_regions` — справочник регионов Директа (`dictionaries.get`, `GeoRegions`): поиск кода по названию и обратная проверка готовых кодов. Директ коды не валидирует, поэтому неверный `geo_ids` или `RegionIds` не вызывает ошибку, а молча даёт данные и показы по другому региону; коды, которых нет в справочнике, теперь возвращаются списком `unknown_ids`. Совпадения приходят с путём до корня — «Москва» это и город `213`, и «Москва и область» `1`. Справочник загружается один раз на процесс, целиком в контекст не выгружается.
- `direct_account_settings` — настройки кабинета, которых нет в Reports API: корректировки ставок (`bidmodifiers.get`), условия ретаргетинга (`retargetinglists.get`) и общие наборы минус-фраз (`negativekeywordsharedsets.get`). Отчёт показывает статистику по срезам `Device`, `Gender`, `Age`, но не выставленный коэффициент, а «нет мобильных конверсий» и «на мобильные стоит −100%» — разные диагнозы. Секции читаются независимо: ошибка одной приходит полем `error` внутри неё. Список кампаний режется на пачки по 10, как требует `bidmodifiers.get`, а усечение выборки больше 50 кампаний отмечается полем `truncated`.
- `direct_wordstat` — частотность Яндекс Вордстата: спрос по фразе, вложенные и похожие запросы. До 50 фраз за вызов, фильтр по минимальной частотности, регионы Директа. Полный список сохраняется тем же TSV, что и отчёты, и читается через `direct_read_report`; в ответ уходит сводка по каждой фразе. Метод живёт в устаревшем API v4 — аналога в v5 нет, — поэтому недоступен в песочнице, а баллы v4 в поле `units` не попадают. Отчёты Вордстата удаляются из очереди аккаунта сразу после выгрузки, в том числе когда вызов упал.
- База знаний по Яндекс Директу как MCP-ресурсы: оглавление `direct://kb` и 11 документов `direct://kb/<имя>` — чек-лист запуска, технические лимиты, контракт записи в API, стратегии и бюджеты, цели Метрики, работа с фразами и минус-словами, таргетинги и корректировки, плейбук донастройки, рецепты отчётов, границы самого сервера. Источники: официальная справка Директа и документация API v5, материалы eLama, публичная практика агентств.
- Инструкции сервера называют правила, нарушение которых не даёт ошибки API и потому проходит незамеченным: микроединицы в денежных полях, обязательный автотаргетинг в поисковой группе, лимиты текстов до вызова.
- `YD_DEFAULT_WEEKLY_BUDGET` — недельный бюджет кампании по умолчанию; попадает в инструкции, чтобы не проговаривать одну и ту же сумму на каждом запуске.

### Fixed

- Запуск `python -m yadirect_mcp` — команда из всех примеров подключения падала с `cannot be directly executed`, потому что в пакете не было `__main__.py`.
- Отчёт больше не теряется, если в TSV попалась строка с лишним разделителем: файл сохраняется до разбора, а ошибка возвращается полем `parse_error`.
- Итоги по отчётам с целями Метрики: колонки вида `Conversions_<цель>_<атрибуция>` больше не выпадают из `totals`, производные метрики пересчитываются по каждой цели.
- Поллинг офлайн-отчёта переживает нечисловой заголовок `retryIn` вместо аварийного завершения.
- Ответы `502`, `503` и `504` от балансировщика повторяются, а не отбрасывают уже поставленный в очередь отчёт.
- Частичное создание объектов кампании: ID из успешных пакетов сохраняются в ответе, если следующий пакет упал.
- Выгруженный TSV записывается байт в байт как пришёл от API, без подстановки CRLF на Windows.

### Security

- Каталог `YD_OUT_DIR` закрыт и на запись: `client_login` с `..` и разделителями пути больше не уводит файл отчёта за его пределы.

### Planned

- Яндекс Метрика, пакетные отчёты и дисковый кеш закрытых периодов.
- Переезд Вордстата с устаревшего API v4 на Yandex Cloud Search API.

## [0.2.0] - 2026-07-16

### Added

- Защищённый режим `campaign_setup`.
- Preview и точная confirmation-фраза перед записью.
- Последовательное создание кампании, групп, объявлений и ключевых фраз.
- Сохранение созданных ID и ошибок при частично выполненной операции.
- Полная документация для Windows, Linux, Claude Code, Codex, Hermes и ZCode.
- GitHub Actions CI, шаблоны сообщества и релизная документация.

### Security

- Режим отчётности остаётся режимом по умолчанию.
- Кампания не активируется автоматически.
- Родительские ID запрещено передавать во вложенных объектах.

## [0.1.0] - 2026-07-16

### Added

- MCP-инструменты `direct_list_clients`, `direct_campaigns`, `direct_report` и `direct_read_report`.
- Поддержка онлайн- и офлайн-отчётов Яндекс Директа.
- Сохранение TSV, totals, preview и постраничное чтение.
- Белый список клиентских логинов и контроль очереди отчётов.
