# Участие в разработке

Спасибо за интерес к yadirect-mcp. Исправления ошибок, тесты и улучшения документации приветствуются.

## Локальная настройка

```bash
python -m venv .venv
python -m pip install --upgrade pip
python -m pip install -e ".[dev]"
```

На Windows используйте `.venv\Scripts\python.exe` вместо `python`, если виртуальное окружение не активировано.

## Перед pull request

```bash
python -m ruff check .
python -m pytest -q
python -m build
python -m twine check dist/*
```

Pull request должен:

- решать одну понятную задачу;
- включать тест для изменённого поведения;
- не содержать OAuth-токены, реальные клиентские логины и выгруженные отчёты;
- сохранять безопасный `YD_MODE=report` по умолчанию;
- не добавлять автоматический запуск кампаний;
- обновлять README и CHANGELOG при изменении публичного поведения.

## Стиль

- Python 3.11+ и type hints для публичного кода.
- Логи MCP-сервера только в `stderr`; `stdout` занят stdio-протоколом.
- Ошибки API должны возвращать полезные `error_code` и `request_id`, если они доступны.
- Новые write-операции требуют отдельной модели угроз, preview и явного подтверждения.

## Сообщение об ошибке

Укажите ОС, версию Python, MCP-клиент, режим `YD_MODE`, шаги воспроизведения и обезличенный фрагмент ошибки. Никогда не публикуйте `YD_TOKEN`.
